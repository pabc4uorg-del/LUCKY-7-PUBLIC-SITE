How Lucky 7 handles account and usage information.

DATA MINIMISATION

Lucky 7 is designed to collect only information needed to operate accounts, analysis, security and payment records. Passwords must never be stored in plain text, and payment secret keys are never placed in public website code.

FIXTURE DATA

Fixture text and screenshots should be retained only as long as operationally necessary. Production retention rules will be published before public account/payment launch.
